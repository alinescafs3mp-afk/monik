# Sol: начать здесь

> Историческая инструкция передачи. Обязательные пункты закрыты в v0.1.1–0.1.2; актуальный результат находится в `docs/ACCEPTANCE.md`.

Владелец Дест передаёт тебе monik для завершения, публикации в `alinescafs3mp-afk/monik` → `main` и полного развёртывания на своей машине. Это разрешение на работу с **monik**, не на изменение работающей Пятницы, моделей, сессий Астры, hooks или Sol-link.

## Маршрут

1. Прочитай `AGENTS.md`, `docs/SOL_HANDOFF_RU.md` и `docs/RELEASE_BACKLOG_RU.md`.
2. За основу возьми **эту** папку проекта. База передачи: `40b5424143a5d2d80717089c52085fce3d5bf4fd`. Старые архивы из переписки и каталог REFERENCE_HISTORY являются только справочными материалами.
3. Проверь новый график по `docs/TOKEN_GRAPH_RU.md`; актуальная проверка сборки описана в `docs/HANDOFF_ACCEPTANCE_20260910.md`. Старые отчёты не являются приёмкой текущего кода.
4. Закрой обязательные задачи, прогоняй тесты после правок. Зарегистрируй отсутствующую команду TUI и проверь установленный пакет, а не только импорт модулей.
5. Согласуй изменения с актуальным origin/main, запушь обычным fast-forward без force. Разверни именно опубликованный проверенный состав по `docs/DEPLOYMENT_FOR_SOL_RU.md`.
6. Закончи короткой русской памяткой владельцу: фактический адрес, вход, TUI, график, обновление/журнал/резервная копия. Не оставляй только код и список задач вместо установки.

В полном архиве рядом с проектом есть `VERIFICATION/`, `PATCHES/` и приватное исходное обследование. **Не добавляй в Git родительский каталог архива целиком.** Приватный архив, реальные журналы, токены и БД не должны попасть в публичный репозиторий.

Новый график уже реализован как отдельная вкладка `/token-graph`: 24/12/6/3/2/1 ч, ряды профилей, выбор метрики, детали точки, таблица, LIVE и пауза экрана. Это начальная рабочая реализация с тестами, не заверенная эксплуатация на машине владельца. Версия пакета пока 0.1.0, config и SQLite schema остаются v1.
