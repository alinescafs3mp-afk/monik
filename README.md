# monik · Codex Observatory

Локальный read-only монитор независимых Codex TUI. Русский интерфейс, собственная SQLite, история, поиск, токены и снимки лимитов. Монитор не вызывает модели и не управляет Codex.

Реализация и воспроизводимые тесты добавляются в этот репозиторий. Исходное приватное обследование сюда не публикуется.
