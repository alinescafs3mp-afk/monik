# Терминальный клиент: состояние интеграции

## Что уже исправлено

Модуль `monik/tui.py` обращается к существующему HTTP-серверу, а не создаёт ещё один Collector. В этой итерации исправлены работа паузы, выбор события и справка. Настройки и процессы Codex не меняются.

При прокрутке либо выборе события незавершённый запрос больше не заменяет уже читаемый снимок. Ввод поиска приостанавливает автоматические обновления. Фиксированный момент T и старые страницы обновляются только по явному запросу. Справка не сбрасывает текущий раздел. Выбранное событие отмечено, перемещается в видимую область и именно оно открывается по Enter.

Нестандартное числовое значение сервера отображается как «нет измерения» вместо падения клиента. Ноль остаётся нулём. Это защита отображения, не исправление нормализатора источников. Русские подписи не изменяют model/effort/tier, идентификаторы и исходные сообщения. Управляющие последовательности не передаются терминалу из данных.

## Что ещё не подключено

**Штатной подкоманды `monik tui` в опубликованном CLI пока нет.** Изменение CLI было отклонено инструментом записи, поэтому в этот набор оно не включено. Этот документ не предлагает альтернативный исполняемый способ подключения вместо отклонённого изменения.

Нельзя считать наличие модуля полноценной установленной функцией или релизом 0.2. Следующий шаг интеграции должен включать штатную команду, установленный пакет и повторную проверку настоящего HTTP/PTY именно опубликованного комплекта.

## Проверки этой итерации

База: `f8178622de24b6cc685b0b6f9e1a869d7c4dd56e`. Python 3.13.5, SQLite 3.46.1.

В `tests/test_tui_behavior.py` находятся десять компонентных проверок: валидация параметров, нестандартные числа, очистка управляющих последовательностей и Unicode-ширина, неизменность технических значений, отметка выбранного события, отмена устаревшего ответа при прокрутке, ввод поиска, справка, фиксированный T и открытие выбранного события.

Общий набор после уточнения четырёх устаревших ожиданий: **54 теста, 53 PASS, 1 SKIP**, без expectedFailure. Пропуск относится к нативному Landlock в контейнере. Контрольные фикстуры: **11 PASS**. Настоящий loopback HTTP/SSE: **23 PASS**. Веб-код, нормализатор, HTTP-модуль, схема SQLite, Collector, CLI и установщик этим набором не меняются.

В трёх старых проверках сообщения теперь проверяются отдельно от метаданных root_binding. Метаданные также явно проверяются, а не игнорируются. Для конфликтного usage независимо проверены исходная каноническая сумма, обе доставки provenance и исключение спорного ответа из подтверждённой суммы. Ошибка записи по-прежнему обязана откатить партию и не продвинуть её курсор.

```bash
python -m unittest discover -s tests -p 'test_tui_behavior.py' -v
python -m unittest discover -s tests -p 'test_*.py' -v
python tests/fixture_validator.py tests
python tests/wire_acceptance.py --output /tmp/monik-wire.json
```

Это не новая приёмка реальных Codex TUI, нативной браузерной сети, systemd/HTTPS или телефона. Результаты локального кандидата с незаписанным CLI не выдаются за результаты содержимого main.

Контракт curses и восстановления терминала: https://docs.python.org/3/library/curses.html
