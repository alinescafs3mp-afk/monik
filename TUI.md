# Терминальный клиент: состояние интеграции

## Текущий состав

Полировка выполнена поверх `fd86ffb800a07f5e9075f1fca3ea26a8a9cd797c`. Изменение клиента: `c86c274d023a393aa613f5586e8b2c465229667f`; десять новых регрессионных проверок добавлены в `8eb4d8437e7768249a30dbb3d3d1f7e5cd9c990a`.

`monik/tui.py` читает существующий HTTP API. Собственного Collector, управляющего канала Codex и вызовов моделей в нём нет. В этой итерации меняются только форматирование терминального экрана, тесты и данный документ. HTTP-сервер, веб-интерфейс, конфигурация, схема БД, установщик и зависимости остаются прежними.

## Что стало лучше

Раньше каждый цикл ожидания клавиши заново форматировал весь снимок, даже при паузе, чтении истории и неизменных данных. Теперь сохраняется один форматированный снимок. Повторное форматирование происходит при новом объекте ответа, изменении раздела, выбранного события или ширины терминала. Удерживается ссылка на сам объект данных, поэтому повторное использование Python object ID не может выдать старый текст за новый ответ.

Это кэш форматирования, а не остановка ввода и не обещание отсутствия перерисовки curses. Заголовки, ввод и видимая область продолжают обновляться. Интервалы сети и правила автоматического получения событий не изменены.

В контрольном сценарии начальная отрисовка и 20 холостых циклов вызывают полное форматирование **один раз вместо 21**. Прокрутка не форматирует заново весь снимок. Новые данные, выбор следующего события и resize по-прежнему немедленно формируют нужный текст.

Длинная логическая строка теперь переносится за один проход после очистки. Ранее при каждом переносе `clip()` снова обрабатывал весь оставшийся хвост строки. В синтетическом примере с повторяющимся русским текстом, диакритикой и широкими символами прежний код вызывал очистку 363 раза; новая проверка требует менее 20 вызовов при том же содержимом. Это характеристика конкретного теста, не замер CPU на машине владельца.

Сохранены предыдущие исправления: запоздавший ответ не заменяет снимок при паузе или вводе поиска; справка не сбрасывает раздел; выбранное событие видно и открывается по Enter; фильтр Sol не показывает карточку Astra. Фиксированный T и старые страницы не начинают автоматически опрашиваться из-за кэша.

## Перевод и безопасность отображения

Подписи и пояснения остаются русскими. Model/effort/tier, идентификаторы, пути, команды и исходные сообщения не переводятся. Очистка терминальных управляющих последовательностей не ослаблена: строки проходят её до форматирования и при выводе видимых строк. Контракт переноса проверяется для кириллицы, комбинируемых диакритических знаков, широких символов, emoji, табуляции, переносов, ANSI и bidi-управления.

## Проверки опубликованного Python-состава

Среда: Python 3.13.5, SQLite 3.46.1. Исходные Python-модули и прежние unittest-файлы восстановлены из доступных копий и чтения GitHub, затем сверены с Git blob SHA исходного main. Сетевой clone в контейнере не выполнен. Опубликованный `tui.py` совпадает с проверенным локальным файлом.

| Проверка | Результат |
|---|---|
| Полный unittest-набор | **83 теста: 82 PASS, 1 SKIP, 0 FAIL**, без expectedFailure |
| Новый `tests/test_tui_render_cache.py` | **10 PASS** |
| Прежние проверки состояния и фильтра профиля TUI | Сохранены и проходят в общем наборе |
| Контрольные фикстуры | **11 PASS** |
| Настоящий loopback HTTP/SSE | **23 PASS** |

До изменений восемь новых проверок кэша падали из-за повторного форматирования. Отдельно воспроизведена избыточная повторная обработка длинной строки. Проверка эквивалентности переноса проходит как до, так и после оптимизации.

Новые тесты используют искусственный экран и управляемую очередь ответов. Это не новый PTY-прогон, не измерение реального терминала и не приёмка владельческих Codex TUI. Единственный пропуск общего набора относится к недоступному native Landlock в контейнере. Браузер, Android, systemd и HTTPS на машине владельца в этой итерации не проверялись.

```bash
python -m unittest discover -s tests -p 'test_tui_render_cache.py' -v
python -m unittest discover -s tests -p 'test_*.py' -v
python tests/fixture_validator.py tests
python tests/wire_acceptance.py --output /tmp/monik-wire.json
```

## Что остаётся открытым

**Штатная подкоманда `monik tui` всё ещё не зарегистрирована в опубликованном CLI.** Очередная операция её записи отклонена инструментом; обходной исполняемый способ подключения не добавлен. Наличие улучшенного модуля пока не означает наличие команды в установленном пакете. Версия пакета остаётся 0.1.0, полный релиз 0.2 не объявлен.

Также воспроизведён ложный конфликт при повторном импорте численно равного времени сброса лимита, представленного как JSON int/float. Проверялось сохранение исходной канонической записи без переписывания данных, но операция изменения хранения была отклонена и **не вошла в main**. Это отдельное незакрытое замечание, не результат этой полировки TUI.

Пройденные проверки не означают полной production-приёмки. Остаются штатная CLI-интеграция, её проверка установленным пакетом через HTTP/PTY и испытание на целевом хосте. Настройки и процессы Codex для обновления этих файлов перезапускать или менять не требуется.
