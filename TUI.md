## Возвращение из подробностей события

Раньше клавиша `l` в подробностях снимала исторический фильтр, но оставляла пользователя на том же событии. Заголовок сообщал LIVE, хотя клиент не возвращался к ленте и не запрашивал её обновления.

Теперь `l` и её эквивалент в русской раскладке `д` возвращают на исходную ленту, очищают идентификатор открытого события, страницу его данных, исторический момент T и старый курсор ленты. Пауза снимается; запрашивается новый снимок. Выбранный профиль и текстовый поиск сохраняются.

Поиск, начатый через `/` из подробностей, больше не передаёт в запрос ленты идентификатор прежнего события и смещение его данных. При этом явно установленный исторический момент сохраняется: поиск в прошлом не становится поиском по LIVE без действия владельца.

Обычный `Esc` имеет другое назначение: возвращает к исходному историческому срезу и странице, не принуждая к LIVE. Отмена ввода поиска оставляет открытые подробности на месте. Пагинация данных события по `n` продолжает читать именно выбранное событие.

Эти различия закреплены восемью проверками в `tests/test_tui_navigation.py`. На прежнем клиенте пять из них падали. После изменения проходят все восемь без изменения ожиданий.

## Сохранённая полировка

Неизменный снимок не форматируется на каждом цикле ожидания клавиши. Повторное форматирование происходит при новом объекте ответа, смене раздела, выбранного события или ширины терминала. Хранится ссылка на сам объект данных, поэтому повторное использование Python object ID не выдаёт старый текст за новый ответ. Заголовки, ввод и видимая область продолжают обновляться.

Длинная логическая строка переносится за один проход после очистки. Проверки сохраняют результат для кириллицы, комбинируемых диакритических знаков, широких символов, emoji, табуляции, ANSI и bidi-управления. Кэш форматирования не меняет интервалы сети и не останавливает обработку клавиш.

Запоздавший ответ не заменяет снимок при паузе или вводе поиска. Справка сохраняет раздел. Выбранное событие отмечается, попадает в видимую область и открывается по Enter. Фильтр Sol не показывает карточку Astra. Старые страницы и фиксированный T не начинают автоматически обновляться.

Подписи и пояснения остаются русскими. Названия моделей, effort/tier, ID, пути, команды, код и исходные сообщения не переводятся. Очистка терминальных управляющих последовательностей не ослаблена.

## Что остаётся открытым

Регистрация `monik tui` и отдельное исправление ложного конфликта численно одинакового времени сброса лимита в JSON int/float снова не прошли запись инструментом. Они не включены в main и не добавлены альтернативным исполняемым способом. Результаты их локальных кандидатов не входят в приведённые результаты опубликованного состава. CLI и storage.py оставлены без изменений.

Для полноценной интеграции остаются штатная подкоманда, её проверка установленным пакетом через настоящий HTTP/PTY и целевая приёмка на машине владельца. Полная production-приёмка не объявляется. Ради обновления файлов клиента не нужно перезапускать сервер monik, Астру, Сола или их дочерние задачи.
