# Закрытие замечания I5: согласованный обзор

Этот небольшой независимый набор исправляет только чтение собственной SQLite monik. Изменения нормализатора, учёта токенов, HTTP/CLI и полного интерфейсного кандидата сюда не входят.

## Изменение

Вложенные read-проекции Store используют одно соединение и одну транзакцию в пределах потока. Весь overview, включая карточки и конечный cursor, выполняется в этой транзакции. В другом потоке создаётся своё соединение; write-lock и прежняя сериализация записей сохранены. После выхода или исключения сохранённая ссылка на соединение очищается.

Новая собственная база создаётся сразу с правами 0600. SQLite-схема остаётся v1, идентичность событий, конфигурация и источники Codex не меняются.

## Регрессии

`tests/test_snapshot_consistency.py` содержит шесть проверок: переиспользование read-соединения, невидимость нового коммита внутри начатого snapshot, одно фактическое соединение на overview, очистка после исключения, изоляция потоков, сохранение схемы/идентичности/дедупликации.

На точной базе 43345b6 три из шести тестов воспроизводили несогласованность. После изменения **все шесть проходят** на Python 3.13.5 / SQLite 3.46.1. Источники полностью искусственные, в отдельных временных каталогах.

```bash
python -m unittest discover -s tests -p 'test_snapshot_consistency.py' -v
```

Четыре расхождения старого общего набора с уже изменёнными ожиданиями описаны отдельно в INTEGRATION_AUDIT_20260910.md и этим набором не скрываются. Замечания I1–I4 не объявляются закрытыми. Это исправление согласованности, не полный релиз 0.2 и не приёмка на настоящих TUI владельца.
