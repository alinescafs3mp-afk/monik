# TUI: проверка фильтра профиля

Проверенная исполняемая база: `4fc1f8a28a2aaffcc2e99f35b398ee6e6b74b6a9`. Она появилась в main во время работы над интеграцией. Её изменения паузы, выбора события, справки и регрессионные тесты сохранены. Этот коммит добавляет только независимую диагностику и данный документ, не меняет приложение.

## Воспроизведённый дефект

При запросе обзора профиля Sol сервер возвращает карточки обоих профилей. Терминальный клиент передаёт параметр запроса, но не ограничивает полученные карточки. В результате разовый и фоновый режимы обзора продолжают показывать Astra. Это ошибка представления, не смешивание сохранённых token-измерений и не изменение аккаунтов.

`diagnostics/check_tui_profile.py` проверяет оба пути на искусственном ответе. Сетевой клиент подменён; настоящие журналы, сервер и Codex не требуются. На указанном main результат `ok=false`, обе проверки фильтра дают false, поток клиента корректно останавливается. Скрипт завершается кодом 1 при воспроизведении дефекта. Он намеренно отделён от основного набора: это открытое замечание, а не замаскированный успешный тест.

```bash
python diagnostics/check_tui_profile.py
```

После исправления оба значения должны стать true без изменения диагностического контракта. Сам скрипт не исправляет клиент и не предоставляет альтернативную команду запуска.

## Повторённые проверки main

Python 3.13.5, SQLite 3.46.1. SHA исполняемых Python-модулей и трёх unittest-файлов сверены с опубликованными файлами. Основной набор: 54 теста, **53 PASS, 1 SKIP**, без expectedFailure. Настоящий loopback HTTP/SSE: **23 PASS**. Фикстуры: **11 PASS**. Пропуск касается native Landlock в контейнере.

Экранные регрессии из параллельного коммита, включая фиксированный T, отсутствие обновлений при вводе поиска и открытие выбранного события, проходят. Эти проверки не заменяют реальную приёмку TUI владельца, Android, TLS/systemd или нативного браузерного транспорта.

## Граница публикации

Запись изменения CLI была заблокирована инструментом. Позднее также была заблокирована запись объединённого TUI с исправлением фильтра. Ветки не переключались на эти кандидатные деревья. CLI, версия пакета и SQLite-схема остаются прежними. Штатная команда `monik tui` в main по-прежнему не зарегистрирована.

Пройденные локальные проверки установочного кандидата не являются приёмкой опубликованной версии. Полный релиз 0.2 не объявляется. Остаются интеграция CLI, этот дефект фильтра и ранее описанные замечания к нормализации полей и семантике поздних конфликтов. Исходники и проверки параллельного коммита не заменены старой копией.
