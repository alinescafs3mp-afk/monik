# Язык и поведение интерфейсов

Пользовательский интерфейс monik по умолчанию русскоязычный. Переводятся навигация, действия, подсказки, сообщения об ошибках, состояния загрузки и объяснения качества данных.

Не переводятся и не изменяются названия моделей, значения `reasoning_effort` и `service_tier`, UUID, имена файлов, пути, команды, ключи JSON/API, исходный код и исходные сообщения агентов. Технический идентификатор допустимо сопровождать русским пояснением, но нельзя подменять его локализованной строкой в данных.

Веб-интерфейс и терминальный клиент должны одинаково различать отсутствие измерения, нулевое значение, устаревшее свидетельство, частичное покрытие и ошибку источника. Наличие соединения с сервером само по себе не подтверждает активность Codex.

Пауза отображения не останавливает сбор данных. Чтение старых сообщений не должно автоматически переносить пользователя к новым. Переход в LIVE и смена исторического момента должны быть явными.

Терминальный клиент подключается к уже работающему серверу monik. Он не создаёт второй сборщик, не читает источники Codex напрямую и не отправляет управляющие команды агентам. Выход из клиента не останавливает сервер или TUI Codex. Управляющие последовательности из наблюдаемых данных нельзя передавать в терминал без очистки.

Эта политика задаёт требования проверки, а не объявляет все функции реализованными или испытанными.
