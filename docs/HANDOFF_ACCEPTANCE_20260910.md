График проверяет half-open границы, шесть интервалов, максимальный размер ряда, dedupe, cached/reasoning subsets, optional counts, настоящий ноль, неизвестные значения, исключение конфликтов с момента обнаружения, отсутствие подмешивания позднего backfill в fixed at, missing source time, профиль/детей, read-only запросы, auth и ошибочные параметры.

DOM-прогон проверяет все периоды, видимые точки, 360/390/412/768/1440 px, размеры кнопок, читаемые SVG viewBox, обе темы, метрики, легенду, ползунок, числовую таблицу, паузу/догон, новые commits, очистку состояния при 401 и отсутствие восстановления private data через resize/метрику. Проверен единственный ResizeObserver после смены всех периодов. Во время проверки исправлены дублирование observer и сохранение приватного in-memory снимка после 401.

Транспорт DOM-прогона обозначен явно: настоящий ASGI API вызывается мостом, EventSource/history в about:blank подменены тестовыми адаптерами. Отдельные первые три HTTP-проверки используют реальные loopback TCP-запросы. Это **не** доказательство нативного browser→SSE, TLS, Android или production Landlock. Политику браузера не меняли.

## Воспроизведение

```bash
python -m unittest discover -s tests -p 'test_*.py' -v
python tests/fixture_validator.py tests
python tests/wire_acceptance.py --output /tmp/monik-wire.json
python tests/graph_browser_acceptance.py --output /tmp/monik-graph
```

После упаковки полный архив проверяется контрольными суммами и повторным unittest из распакованной основной папки; фактический результат этого шага находится в `VERIFICATION/archive_check.json`, не в старых отчётах.

## Что не принято здесь

Штатная регистрация TUI, int/float replay compatibility, UI-каталог профилей, установка на хосте, systemd, настоящий браузер/Android, TLS и невмешательство O13 в живые TUI остаются задачами Сола. Реальные измерения CPU/RAM и нагрузки по 24-часовому окну не сделаны. Не заявлены полный O1–O20 и готовый production-релиз.

Пользователь просил начать график и передать остаток CLI-Солу; это именно такой исходный комплект. Version/config/schema не повышались для создания видимости законченного релиза.
