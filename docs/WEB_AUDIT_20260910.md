# Обновление веб-интерфейса, 10 сентября 2026

## Граница публикации

Исходная точка: `f8178622de24b6cc685b0b6f9e1a869d7c4dd56e`. Это самостоятельное обновление веб-интерфейса, **не релиз 0.2.0**. Python-код сервера, сборщик, TUI, CLI, зависимости, конфигурация и схема SQLite в этом изменении не меняются.

Включены три файла `monik/web/`, обновлённые `tests/offline_browser.py` и `tests/test_core.py`, этот отчёт и его JSON-сводка. Документ `LOCAL_CANDIDATE_0.2_STATUS.md` по-прежнему описывает отдельно подготовленный, но не полностью опубликованный кандидат.

## Изменения интерфейса

Пауза останавливает только обновление экрана; сборщик продолжает сохранять события. Добавлены ручное обновление, интервалы «За час», «За сутки», «Всё время» и возврат к более поздней странице ленты. Чтение старых сообщений не переносит пользователя к новым автоматически.

Обновления ограничены по частоте, а не откладываются бесконечно при плотном потоке уведомлений. Устаревшие ответы после смены экрана или выхода не возвращают прежние данные. При выходе очищается содержимое интерфейса; повторный вход восстанавливает LIVE. Некорректный момент T в ссылке показывает ошибку без разрушения интерфейса.

Русские названия состояний, окон лимитов и типовые ошибки согласованы с существующим `labels.ru.json`. Словарь встроен в статический клиент: новый маршрут сервера не требуется. Названия моделей, `ultra`, `default`, ID, пути, ключи API, код и исходные сообщения не переводятся. Неизвестное измерение не отображается нулём.

Вёрстка проверена на ширинах 360, 390, 412, 768 и 1440 CSS px, в обеих темах. Длинные данные прокручиваются внутри соответствующих областей.

## Повторная проверка именно опубликованного состава

Среда: Python 3.13.5, SQLite 3.46.1. Серверные файлы побайтово совпадают с исходной точкой. Локальный checkout реконструирован из проверенных Git-объектов и архива; сетевой clone в среде недоступен.

| Проверка | Результат |
|---|---|
| unittest, 44 теста | 43 PASS, 1 SKIP, без expectedFailure |
| Контрольные данные | 11 PASS |
| Настоящий loopback HTTP/SSE | 23 PASS |
| Chromium DOM/CSS/JS с тестовым транспортом | 39 PASS |
| Синтаксис Python, JavaScript и shell | PASS |

Пропуск относится к нативному Landlock, ABI которого недоступен в контейнере. Отказ запуска без него проверен. Навигация Chromium к локальному серверу блокируется административной политикой среды; политика не менялась. Поэтому DOM-тест использует явно обозначенные ASGI-мост и замену EventSource. Это **не** проверка нативного браузерного HTTP/SSE или физического Android. Настоящий HTTP/SSE испытывается отдельным Python-клиентом.

Четыре устаревших утверждения тестов приведены к уже существующему поведению сервера. Счётчики сообщений теперь считают сообщения, не добавленные ранее свидетельства root_binding. Тест спорного usage проверяет исключение из суммы и одновременно сохранение исходных 1100 токенов в канонической записи. Проверки атомарности курсора, ротации и принадлежности профилю сохранены. Ошибки не скрыты expectedFailure или удалением тестов.

## Что этим изменением не закрыто

Рабочая приёмка с настоящими Codex TUI, systemd/HTTPS, нативным Landlock и Android не выполнена. Общая готовность production и полная приёмка O1–O20 не заявляются.

В неизменённом сервере остаются замечания по нормализации некорректных полей лимитов, времени видимости позднего конфликта и контракту типов настроек. Изменения этих модулей, CLI и конфигурации не опубликованы после отказа инструмента записи. Их отсутствие не маскируется обновлённой вёрсткой.

Исходник отдельного TUI уже присутствует в репозитории, но команда `monik tui` в опубликованном CLI ещё не подключена. Не используйте инструкции от локального кандидата 0.2 как описание этого коммита. Версия пакета остаётся 0.1.0.

Параллельно опубликованное исправление I5 (`f8178622`) сохранено вместе с шестью регрессионными тестами. Новый обзор использует одну read-транзакцию. Этот код не заменяется интерфейсным обновлением.

## Воспроизведение

Из корня репозитория в отдельном окружении:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-test.txt
.venv/bin/python -m unittest discover -s tests -p 'test_*.py' -v
.venv/bin/python tests/fixture_validator.py tests
.venv/bin/python tests/wire_acceptance.py --output /tmp/monik-wire.json
.venv/bin/python tests/offline_browser.py --output /tmp/monik-ui
```

Для DOM-проверки требуется установленный `/usr/bin/chromium`. Все тестовые источники искусственные или обезличенные, рабочие файлы Codex не изменяются. Исторические отчёты в `docs/evidence/` не подменяют эту проверку; актуальная сводка: `WEB_AUDIT_20260910.json`.

## Обновление существующей установки

Обновляется код в каталоге, из которого установлен monik: `git pull --ff-only`, затем обычная перезагрузка страницы браузера. Для данного изменения серверные модули и зависимости прежние; миграция базы и повторный запуск установщика не нужны. При изменениях в локальном рабочем дереве сначала разберите их, не применяйте `git reset --hard`. Если необходим перезапуск, перезапускайте только используемую службу monik, не Codex.
